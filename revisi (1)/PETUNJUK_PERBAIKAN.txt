PETUNJUK PEMASANGAN REVISI KELOLA KELAS

1. Ekstrak ZIP ini. Folder project berada di dalam folder "revisi (1)".
2. Salin isi folder tersebut ke folder project XAMPP Anda (misalnya C:\xampp\htdocs\ukk-2026\revisi), timpa file yang lama.
3. Buka phpMyAdmin dan pilih database db_ukk_2026.
4. Buka tab SQL, lalu buka dan jalankan file PERBAIKAN_DATABASE_TAHUN_AJARAN_KELAS.sql.
5. File SQL ini khusus untuk database yang belum memiliki kolom t_kelas.tahun_ajaran_id. Jalankan satu kali saja. Jangan jalankan jika kolom itu sudah ada.
6. Buka kembali menu Kelola Kelas. Tambah/Edit Kelas akan mengambil pilihan tahun ajaran dari tabel t_tahun_ajaran.

CATATAN
- File db_ukk_2026 (3).sql dalam project merupakan dump struktur/data contoh; jangan impor ulang ke database yang sudah berisi data kecuali memang ingin mengganti database.
- Jika muncul error duplicate column atau duplicate key, hentikan dan kirim pesan error tersebut; jangan mengulang ALTER TABLE.
- Pemeriksaan sintaks PHP dilakukan pada file PHP project. Koneksi MySQL tetap perlu diuji di XAMPP milik Anda.
