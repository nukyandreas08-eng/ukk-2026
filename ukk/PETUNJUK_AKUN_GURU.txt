PENGATURAN AKUN LOGIN SELURUH GURU

1. Backup database terlebih dahulu.
2. Untuk database yang SUDAH ADA: buka phpMyAdmin > db_ukk_2026 > SQL, jalankan isi MIGRASI_AKUN_GURU.sql satu kali.
   Jika kolom username sudah ada, jangan jalankan ALTER TABLE lagi.
3. Login sebagai administrator.
4. Buka: http://localhost/ukk-2026/buat_akun_semua_guru.php
   (Sesuaikan nama folder project jika berbeda.)
5. Halaman menampilkan username unik semua guru dan password sementara.
6. Password sementara semua guru: Guru2026!
7. Setiap guru login menggunakan username masing-masing dan password sementara tersebut.
8. Setelah akun berhasil dibuat, HAPUS file buat_akun_semua_guru.php dari folder project.

Untuk database baru yang diimpor dari db_ukk_2026 (1).sql, kolom username sudah disertakan.
Username menggunakan nama guru persis seperti kolom nama pada tabel t_guru. Jika ada nama yang sama, NIP ditambahkan agar username tetap unik.
Password disimpan dalam bentuk hash, bukan teks biasa.

PELAPOR PELANGGARAN:
Nama pelapor diambil otomatis dari relasi akun login (t_users.id -> t_guru.user_id).
Guru tidak perlu mengetik nama pelapor secara manual. Akun guru yang belum terhubung akan ditolak saat menyimpan catatan.
